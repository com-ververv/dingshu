## 1. 采纳建议

当前可接受并进入 MVP 的建议：

- 会话侧栏增加搜索和时间分组。
- 侧栏展示配置状态和当前执行状态。
- 输入框支持按会话保存草稿。
- 支持 MVP slash commands：`/new`、`/clear`、`/settings`、`/auth`、`/search`。
- 空状态文案改成飞书任务导向，不做营销说明。
- 工具调用默认展示紧凑摘要，展开后看参数和结果。
- 敏感操作确认按钮文案改成“拒绝 / 仅本次允许”。
- 长任务状态文案：连接、思考、调用飞书、等待确认、超时提示。
- 设置页展示 Lark 能力数量、lark-cli 路径和授权状态。

## 3. 阶段 15：会话侧栏和配置状态

目标：

- 让用户快速定位会话，并看到配置是否可用。

实现范围：

- 会话列表按时间分组：
  - 今天
  - 昨天
  - 近 7 天
  - 近 30 天
  - 更早
- 新增会话搜索框，按标题和预览过滤。
- 侧栏增加配置状态：
  - 模型 API Key
  - 飞书 appId/appSecret
  - 飞书授权
- 当前会话生成时展示执行中状态；等待审批时展示等待确认。

验收：

- 有历史会话时能按组展示。
- 搜索能过滤会话。
- 未配置时状态清晰并可打开设置。
- `npm run lint`、`npx tsc --noEmit` 通过。

执行记录：

- 会话侧栏已增加搜索框，可按标题和预览过滤会话。
- 会话列表已按“今天 / 昨天 / 近 7 天 / 近 30 天 / 更早”分组展示，并显示最近时间。
- 侧栏已增加配置状态卡片，展示模型、飞书应用、飞书授权，以及当前“空闲 / 正在执行 / 等待确认”状态。
- 空状态文案已改为飞书任务导向，并更新建议指令。
- 已通过 `npm run lint`、`npx tsc --noEmit`。

## 4. 阶段 16：输入框草稿和 slash commands

目标：

- 提升桌面聊天效率。

实现范围：

- 草稿按会话保存到 `localStorage`。
- 切换会话时恢复对应草稿。
- 支持命令：
  - `/new` 新建会话
  - `/clear` 清空当前本地视图并开始新会话
  - `/settings` 打开设置
  - `/auth` 打开设置并切到 Lark 授权区域，MVP 可先打开设置
  - `/search <关键词>` 过滤会话；无关键词时聚焦搜索框
- 发送前识别 slash command，不进入模型。

验收：

- 草稿切换会话后可恢复。
- slash command 不写入聊天消息。
- `npm run lint`、`npx tsc --noEmit` 通过。

执行记录：

- 已按会话 ID 将草稿保存到 `localStorage`，切换会话和新建会话时自动恢复对应草稿。
- 发送消息后会清理当前会话草稿。
- 已支持 `/new`、`/clear`、`/settings`、`/auth`、`/search <关键词>`，命令只触发本地 UI 行为，不进入模型消息。
- `/search` 会更新侧栏会话搜索；无关键词时聚焦搜索框。
- 已通过 `npm run lint`、`npx tsc --noEmit`。

## 5. 阶段 17：工具调用组和长任务反馈

目标：

- 降低多工具调用时的视觉噪音，并给用户明确状态。

实现范围：

- 工具调用列表顶部增加摘要：
  - 总动作数
  - 正在执行数
  - 等待确认数
  - 失败数
- 工具调用默认紧凑展示；等待确认或失败自动展开。
- 审批按钮改为“仅本次允许”和“拒绝”。
- 状态文案本地化：
  - `Connecting` -> `正在连接`
  - `Streaming` -> `正在生成`
  - `Using tool` -> `正在调用飞书`
  - `Waiting approval` -> `等待确认`
  - 超过 15 秒仍未结束显示 `执行时间较长，仍在等待返回`

验收：

- 工具调用摘要显示准确。
- 等待确认能看到确认条。
- 长任务 15 秒后状态变更。
- `npm run lint`、`npx tsc --noEmit` 通过。
