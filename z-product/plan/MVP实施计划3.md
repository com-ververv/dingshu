# Pexar Lark Agent MVP 实施计划 3：UI/UX 打磨

本文基于：

- `z-product/ref/lark-agent-ui-ux-reference.md`
- `z-product/prd/PRD.md`
- `z-product/tech/技术选型.md`
- 当前已实现的聊天、会话、设置、工具调用和 Lark capability registry

执行规则：

1. 每个阶段完成后必须自测。
2. 自测通过后提交 Git。
3. 不引入大规模 UI 重构；优先改善现有 `App.tsx` 和样式，后续再拆组件。
4. 与技术方案不一致时先更新 `z-product/tech/技术选型.md`。

## 1. 采纳建议

当前可接受并进入 MVP 的建议：

- 会话侧栏增加搜索和时间分组。
- 侧栏展示配置状态和当前执行状态。
- 输入框支持按会话保存草稿。
- 支持 MVP slash commands：`/new`、`/clear`、`/settings`、`/auth`、`/search`。
- 空状态文案改成飞书任务导向，不做营销说明。
- 工具调用默认展示紧凑摘要，展开后看参数和结果。
- 敏感操作确认按钮文案改成“拒绝 / 仅本次允许”。
- 长任务状态文案：连接、思考、调用飞书、等待确认、超时提示。
- 设置页展示 Lark 能力数量、lark-cli 路径和授权状态。
- 右侧文档预览 / Artifact 面板，用于飞书文档创建前预览和创建后结果展示。
- `@群名`、`@联系人`、`@文档标题` 对象 picker，用于降低飞书对象选择和工具入参错误率。
- 会话重命名，用于整理长期本地会话历史。

## 2. 暂缓建议

暂不进入 MVP：

- 操作前编辑工具参数。
- 点赞 / 点踩。
- 复杂设置分栏重构。
- 本会话允许某类敏感操作。
- 多版本 diff、内嵌编辑器、批量任务 dashboard。

## 3. 阶段 15：会话侧栏和配置状态

## 4. 阶段 16：输入框草稿和 slash commands

目标：

- 提升桌面聊天效率。

实现范围：

- 草稿按会话保存到 `localStorage`。
- 切换会话时恢复对应草稿。
- 支持命令：
  - `/new` 新建会话
  - `/clear` 清空当前本地视图并开始新会话
  - `/settings` 打开设置
  - `/auth` 打开设置并切到 Lark 授权区域，MVP 可先打开设置
  - `/search <关键词>` 过滤会话；无关键词时聚焦搜索框
- 发送前识别 slash command，不进入模型。

验收：

- 草稿切换会话后可恢复。
- slash command 不写入聊天消息。
- `npm run lint`、`npx tsc --noEmit` 通过。

执行记录：

- 已按会话 ID 将草稿保存到 `localStorage`，切换会话和新建会话时自动恢复对应草稿。
- 发送消息后会清理当前会话草稿。
- 已支持 `/new`、`/clear`、`/settings`、`/auth`、`/search <关键词>`，命令只触发本地 UI 行为，不进入模型消息。
- `/search` 会更新侧栏会话搜索；无关键词时聚焦搜索框。
- 已通过 `npm run lint`、`npx tsc --noEmit`。

## 7. 阶段 19：右侧文档预览 / Artifact 面板

目标：

- 在创建或更新飞书文档前，让用户能预览标题、正文和结构化结果。
- 在文档创建成功后，集中展示飞书链接、标题、摘要和后续操作。

实现范围：

- 在聊天工作区右侧增加可收起的 Artifact 面板。
- 面板首版只承载飞书文档类 Artifact：
  - 文档标题
  - Markdown 正文预览
  - 创建 / 更新目标
  - 创建成功后的飞书链接
  - 复制正文 / 复制链接
- `lark_doc_create` 审批前，将待创建内容同步到右侧预览。
- 创建成功后，Artifact 状态从 `draft` 变为 `created`。
- 不做多版本 diff、不做内嵌编辑器、不做表格/图片 Artifact。

验收：

- 用户要求创建飞书文档时，右侧能看到待创建文档预览。
- 拒绝审批后 Artifact 标记为未创建，不展示成功链接。
- 创建成功后 Artifact 展示飞书链接并支持复制。
- 右侧面板可收起，不影响聊天主流程。
- `npm run lint`、`npx tsc --noEmit`、`npm run package` 通过。

执行记录：

- 已在聊天工作区右侧新增可收起 Artifact 面板。
- 首版 Artifact 从 `lark_doc_create` 的 tool event 派生，不新增数据库表。
- 审批前读取 `inputPreview` 中的 `title` 和 `contentPreview` 展示文档草稿。
- 创建成功后读取 `outputPreview` 中的 `url` 和 `token`，支持复制正文、复制链接和打开飞书链接。
- 拒绝或失败时 Artifact 展示未创建 / 失败状态，不展示成功链接。
- 已按 CodePilot 的紧凑三栏工作台风格调整侧栏、消息区、输入区和右侧预览面板视觉。

## 8. 阶段 20：飞书对象 Picker

目标：

- 支持在输入框中通过 `@` 选择飞书群、联系人和文档，减少模型猜测对象名称导致的工具失败。

实现范围：

- 输入框支持触发对象 picker：
  - `@群名`
  - `@联系人`
  - `@文档标题`
- Picker 数据来源：
  - 群：`im_chat_list` / `lark_message_search` 已有群解析能力
  - 联系人：`contact_search_user`
  - 文档：`lark_doc_search` / `drive_search`
- 选中后在输入框插入稳定引用文本，例如：
  - `@[群:研发群](chat_id=oc_xxx)`
  - `@[联系人:张三](open_id=ou_xxx)`
  - `@[文档:评估报告](url=https://...)`
- 发送给模型时保留可读名称和稳定 ID，工具层优先使用稳定 ID。
- 首版只做输入框内对象引用，不做复杂对象管理面板。

验收：

- 输入 `@` 后能搜索并选择群、联系人、文档。
- 选中对象后，消息中保留用户可读名称。
- 工具调用时能优先使用对象 ID / URL，减少二次搜索。
- 无搜索结果、无权限、授权失效时有明确提示。
- `npm run lint`、`npx tsc --noEmit`、`npm run package` 通过。

执行记录：

- 已新增 `larkObject:search` 只读 IPC，Renderer 不直接执行 lark-cli。
- Picker 支持搜索联系人、群聊和文档，结果统一为 `id`、`title`、`subtitle`、`reference`、`url`。
- 输入框识别当前光标前的 `@关键词`，展示分组 picker。
- 选中后插入稳定引用文本：`@[群:...](chat_id=...)`、`@[联系人:...](open_id=...)`、`@[文档:...](url=...)`。
- 搜索失败、无权限或无结果会在 picker 中展示明确状态。

## 9. 阶段 21：会话重命名

目标：

- 让用户能整理本地会话历史，避免长期使用后侧栏难以检索。

实现范围：

- 会话侧栏支持重命名入口。
- 重命名只修改本地 `conversations.title`，不影响消息内容。
- 支持：
  - 侧栏会话项 hover 后显示重命名按钮
  - 当前会话标题双击或菜单重命名
  - Enter 保存，Esc 取消
- 重命名后刷新侧栏并保留当前选中会话。
- 名称为空时拒绝保存；过长标题做长度限制和 UI 截断。

验收：

- 可以重命名当前会话和非当前会话。
- 重启应用后重命名结果仍保留。
- 搜索会话时能按新标题命中。
- 删除、切换、生成中的会话状态不被重命名破坏。
- `npm run lint`、`npx tsc --noEmit`、`npm run package` 通过。

执行记录：

- 已新增 `renameConversation` 数据库方法，只更新本地 `conversations.title`。
- 已新增 `chat:renameConversation` IPC，并同步 preload 与 `window.api` 类型。
- 侧栏会话项 hover 后显示重命名按钮。
- 重命名支持 Enter 保存、Esc 取消、失焦保存。
- 空标题会拒绝保存，标题最多保留 80 字符。
- 重命名后刷新会话列表并保留当前选中会话，侧栏搜索可按新标题命中。
