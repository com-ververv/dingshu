# Pexar Lark Agent — PRD（简洁版 v0.3）

## 产品定位

桌面端（macOS + Windows）的 AI 聊天助手，用自然语言操作飞书。

## 目标用户

所有飞书用户。自带飞书账号和硅基流动 API Key 即可使用，无组织限制。

## 核心价值

- 降低飞书操作成本：常用动作一句话搞定
- 本地可控：授权和数据走用户自己的账号，不经第三方服务器
- 开箱即用：内置 lark-cli，无需额外安装依赖

## 典型场景

| # | 场景 | 示例 |
|---|------|------|
| S1 | 创建飞书云文档 | "把这段内容创建为飞书文档" |
| S2 | 查询群消息 | "总结一下「研发群」今天的讨论" |
| S3 | 搜索文档 | "找一下上周的评估报告" |

其余飞书动作（发消息、查日程、@人等）由 Agent 在对话中自然衔接，不作为独立场景在 MVP 推广。

## 功能需求

### 聊天主界面

- 单窗口、单对话流，流式输出
- 展示工具调用过程（可折叠/展开）
- 支持复制、重新生成

### 飞书能力（lark-cli 内置）

MVP 至少覆盖：

- 文档：创建、读取、搜索
- 消息：发送、查询

其余飞书能力（日历、联系人等）默认开启但不在主推场景。

### 会话管理

- 本地保存历史会话
- 侧边栏可查看、恢复、删除
- 不上云、不同步

### 设置面板

- 硅基流动 API Key（默认模型 `Pro/moonshotai/Kimi-K2.6`）
- 飞书 appId / appSecret（用户自填）
- 飞书账号授权入口（调用 lark-cli 自身的授权流程）

> MVP 不做首次引导。用户在「设置」里自行填入并完成授权。设置未配置时，聊天界面给出明确提示。

## 非功能需求

| 维度 | 要求 |
|------|------|
| 平台 | macOS（Apple Silicon + Intel）、Windows 10/11 |
| 安装 | 单一安装包，内置 lark-cli，无需额外依赖 |
| 凭证安全 | API Key、appSecret 存系统 keychain，不明文落盘 |
| 响应速度 | 首 token < 3s（取决于硅基流动） |
| 语言 | 中英双语（默认中文） |
| 离线 | 无网络时给出明确提示，不崩溃 |

## 不做（MVP 不含）

- 首次引导 / Onboarding 流程
- 多用户 / 云同步
- 定时任务、工作流编排
- 模型切换（固定 Kimi-K2.6）
- 插件机制
- 移动端 / Web 版
- Pexar 自定义业务工具（仅通用飞书能力）

## 成功指标（MVP 上线后 4 周）

- 累计下载 ≥ 500
- 周活留存 ≥ 30%
- "创建飞书文档"场景成功率 ≥ 90%
