# Pexar Lark Agent 功能测试计划

日期：2026-05-28

## 1. 测试依据

- PRD：`z-product/prd/PRD.md`
- Codex session：`019e64f7-b2c9-7a70-a13d-82a9c7809f2b`
- 当前代码分支：`codex/siliconflow-ai-sdk-demo`
- 当前应用形态：Electron + React + TypeScript，主进程通过 IPC 调用 SiliconFlow 和 lark-cli。

## 2. Session 关键信息

历史 session 显示本项目已经从技术方案推进到可运行原型，重点实现和验证过：

- Electron IPC 版聊天界面，而不是本地 HTTP `/api/chat`。
- 主进程使用 Vercel AI SDK `streamText`，模型固定 `Pro/moonshotai/Kimi-K2.6`。
- API Key 优先从安全设置读取，备用 `SILICONFLOW_API_KEY` 环境变量。
- 已有会话列表、会话恢复、软删除、重命名、草稿保存。
- 已有设置面板：SiliconFlow API Key、飞书 appId/appSecret、飞书授权、lark-cli 信息、数据库位置。
- 已有飞书工具：文档创建/读取/搜索，消息发送/搜索，扩展 lark-cli shortcut。
- 已有工具调用 UI：工具过程、审批、结果、artifact 文档预览。
- 已验证过最小 AI SDK tool loop 和 lark-cli 只读 smoke，但未完整验证审批、停止生成、流式工具事件、失败恢复等桌面 UI 链路。

## 3. 测试范围

### 3.1 PRD 必测范围

| 模块 | PRD 要求 | 测试目标 |
|---|---|---|
| 聊天主界面 | 单窗口、单对话流、流式输出 | 启动后能进入聊天界面，发送消息后 assistant 增量输出 |
| 工具过程 | 展示工具调用过程，可折叠/展开 | 触发飞书工具后出现工具卡片，能展开查看输入/结果 |
| 消息操作 | 支持复制、重新生成 | 复制 assistant 内容；检查是否存在重新生成入口及行为 |
| 飞书文档 | 创建、读取、搜索 | 文档搜索/读取可返回结果；创建前需要确认 |
| 飞书消息 | 发送、查询 | 查询可返回结果；发送前需要确认 |
| 会话管理 | 本地保存历史会话，侧边栏查看、恢复、删除 | 创建会话、恢复会话、删除会话、重命名、搜索 |
| 设置面板 | API Key、飞书 appId/appSecret、授权入口 | 保存凭证状态可变；授权入口可启动；状态明确 |
| 未配置提示 | 设置未配置时聊天界面给明确提示 | 无 API Key 时发送被阻止或返回明确错误 |
| 凭证安全 | API Key、appSecret 不明文落盘 | 检查 UI 不回显明文，仓库不写入密钥 |
| 离线/错误 | 无网络时明确提示，不崩溃 | 用无效请求或断网替代场景验证错误 UI |

### 3.2 当前实现补充测试范围

- 顶部配置状态条：模型、飞书应用、飞书授权状态。
- slash command：`/new`、`/clear`、`/settings`、`/auth`、`/search`。
- `@` 飞书对象搜索和 mention 插入。
- 右侧 Artifact 面板展开/收起，文档创建结果的复制/打开入口。
- 停止生成按钮。
- 15 秒长等待状态提示。
- 设置页 Storage / About 基础功能。

## 4. 测试环境

- 操作系统：macOS
- 测试方式：启动 Electron dev 应用，使用 Computer Use 插件操作窗口。
- 启动命令：`npm run dev`
- 预置条件：
  - 如本地已保存 SiliconFlow API Key，可直接测试真实聊天。
  - 如未保存 API Key，只验证未配置提示和设置保存入口，不写入真实密钥。
  - 涉及真实飞书写操作时，只验证审批 UI，不点击最终确认，除非已有明确测试数据和授权。
